# 界面图标需求清单

> 用途：为界面补齐图标资源。**本文只列需求（名称 / 用途 / 尺寸），不放图形设计** —— 后续制作时
> 按「建议文件名」放进 `assets/icons/ui/`，代码侧按名称引用即可。
>
> 约定：
> - 风格：单色线性（1.5～2px 描边）+ 少量强调色，深浅两套主题共用一套（浅色底用深色描边，深色底自动反色）。
> - 格式：`SVG` 源文件 + 导出 `PNG`（16 / 24 / 32 px 三档）；表格里的尺寸是**主要使用尺寸**。
> - 命名：`ui-<分组>-<名称>.svg`，例如 `ui-run-start.svg`。
> - 优先级：**P0** = 没有图标界面明显缺一块；**P1** = 有图标显著更好用；**P2** = 锦上添花。

已有资源（不用再做）：`assets/icons/app.ico`、`app-icon.svg`、`app-mark.svg`、`png/app-*.png`、`png/splash-mark.png`。

## 交付方式

1. 图形源文件放 `assets/icons/ui/src/*.svg`（单色，`currentColor` 或纯黑描边）；
2. 导出放 `assets/icons/ui/png/<name>-{16,24,32}.png`；
3. 代码引用统一走一个 `UiIcons` 静态类（按名称取 `Icon`/`Image`，缓存），不各窗体各写路径。
