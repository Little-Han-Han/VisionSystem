# 使用说明

## 一、鼠标与键盘操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 以光标位置为锚点缩放（指哪放大哪） |
| `Ctrl` + 滚轮 | 快速缩放（步长为普通滚轮的平方） |
| 中键拖拽 | 平移画布 |
| 右键拖拽 | 平移画布 |
| `空格` + 左键拖拽 | 临时平移（松开空格恢复） |
| 左键拖拽图形 | 整体移动图形 |
| 左键拖拽白色方块 | 调整尺寸 / 半径 |
| 左键拖拽金色方块 | 旋转（仅旋转矩形） |
| 左键点空白处 | 取消当前选择 |
| 右键单击 | 弹出菜单：保存图像 / 保存视图截图 / 自适应图像 / 显示辅助十字线 |
| `Delete` | 删除选中图形 |
| `Esc` | 取消正在绘制的图形 / 取消选择 |
| `+` / `-` | 放大 / 缩小一档 |
| `0` | 适应窗口 |
| `1` | 恢复 1:1 |

> 控制点尺寸固定为**屏幕像素**，无论缩放到多少倍，手感都一致。

## 二、交互模式

通过 `ImageViewer.Mode` 切换，类型 `InteractionMode`：

| 模式 | 说明 |
|---|---|
| `Select` | 默认。点击选中图形，拖拽移动，拖控制点改形状 |
| `Pan` | 任意按键拖拽都是平移 |
| `DrawCircle` | 左键按下定圆心，拖动定半径，松开完成 |
| `DrawRectangle` | 拖出轴对齐矩形 |
| `DrawRotatedRect` | 先拖出一个 0° 矩形，再用金色手柄旋转 |
| `DrawRing` | 按下定圆心，拖动定外半径；内半径默认取外半径的一半，之后用内圆控制点调整 |

绘制模式下右键可取消当前绘制。拖动距离小于 4 屏幕像素视为误点击，不会生成图形。

**典型做法**：画完一个图形后把 `Mode` 设回 `Select`，用户即可继续编辑。订阅 `ShapeCreated` 事件自动切回：

```csharp
imageViewer1.ShapeCreated += (s, e) => imageViewer1.Mode = InteractionMode.Select;
```

### 右键菜单

在控件上**右键单击**（不拖动）弹出内置菜单；右键**拖动**仍然是平移画布，两者互不干扰。

| 菜单项 | 功能 |
|---|---|
| 保存图像(&S) | 把当前图像（不含图形叠加）另存为 PNG / JPEG / BMP / TIFF |
| 保存视图截图(&V) | 把当前所见画面（含图形、网格、背景）另存为文件，适合做报告配图 |
| 自适应图像(&F) | 等价于 `FitToWindow()`，缩放至完整可见并居中 |
| 显示辅助十字线(&C) | 开关跟随鼠标的十字线，勾选状态与 `ShowCrosshair` 属性实时同步 |

程序内直接调用（不弹对话框）：

```csharp
// 生成当前视图快照（含图形叠加），自行决定怎么用
Bitmap snap = imageViewer1.CreateSnapshot();

// 需要交互时再弹保存对话框
imageViewer1.SaveImageToFile();      // 保存原始图像
imageViewer1.SaveSnapshotToFile();   // 保存所见即所得的截图
```

往菜单里追加自己的命令：

```csharp
imageViewer1.ViewerContextMenu.Items.Add(
    new ToolStripMenuItem("发送 ROI 到算法", null, (s, e) => SendRoi()));
```

> 灰度图属于索引色，保存为 JPEG 时控件内部会自动转成 24bpp 再写盘。

## 三、集成到你自己的项目

### 方式 A：引用编译好的 DLL（推荐）

1. 双击 `build.bat` 生成 `src\VisionSystem.Controls\bin\Debug\VisionSystem.Controls.dll`
2. 你的项目中「引用 → 添加引用 → 浏览」选中该 DLL
3. 工具箱右键 → 「选择项」→ 浏览同一 DLL，即可把 `ImageViewer` 拖到窗体上

### 方式 B：直接引用项目

1. 把 `VisionSystem.Controls` 项目加入你的解决方案
2. 「添加引用 → 项目」选中它

> 两种方式都要求目标框架为 **.NET Framework 4.8**（或 4.6.1 以上，控件本身未使用更高版本 API）。

### 设计器支持

`ImageViewer` 标记了 `[ToolboxItem(true)]`，编译后会出现在工具箱。
以下属性可在属性窗口中直接调整：`Mode`、`ZoomStep`、`OwnsImage`、`AutoFitOnResize`、`NewShapeColor`、`NewShapeLineWidth`。

`Image`、`Shapes`、`Options`、`Viewport` 标记为 `Browsable(false)`，不会出现在属性窗口，需通过代码访问。

## 四、与 OpenCV 对接

`CvInterop` 不依赖任何 NuGet 包，只要能拿到**数据指针**、**宽高**、**行字节数**就能工作。

### 4.1 OpenCvSharp（C# 项目最常用）

```csharp
using OpenCvSharp;
using VisionSystem.Controls.Interop;

// 读图并显示
using (Mat mat = Cv2.ImRead("board.jpg", ImreadModes.Color))
{
    // mat.Data           -> IntPtr，首像素地址
    // mat.Width / Height -> 宽高
    // mat.Step()         -> 每行字节数（可能含填充）
    imageViewer1.SetCvImage(mat.Data, mat.Width, mat.Height,
                            (int)mat.Step(), CvPixelLayout.Bgr24);
}

// 灰度图
using (Mat gray = new Mat())
{
    Cv2.CvtColor(src, gray, ColorConversionCodes.BGR2GRAY);
    imageViewer1.SetCvImage(gray.Data, gray.Width, gray.Height,
                            (int)gray.Step(), CvPixelLayout.Gray8);
}

// 把控件上的图像取回为 Mat
byte[] bgr = imageViewer1.GetImageBytes(CvPixelLayout.Bgr24);
Mat back = new Mat(h, w, MatType.CV_8UC3, bgr);
```

也可以先转成 `Bitmap` 再交给控件，效果相同：

```csharp
Bitmap bmp = CvInterop.ToBitmap(mat.Data, mat.Width, mat.Height,
                                (int)mat.Step(), CvPixelLayout.Bgr24);
imageViewer1.SetImage(bmp);
```

### 4.2 原生 cv::Mat（C++/CLI 或 P/Invoke）

```cpp
// C++ 侧导出
extern "C" __declspec(dllexport)
const uchar* GetMatData(cv::Mat* m) { return m->data; }
```

```csharp
// C# 侧
IntPtr data = GetMatData(matPtr);
imageViewer1.SetCvImage(data, cols, rows, (int)step, CvPixelLayout.Bgr24);
```

### 4.3 Emgu CV

```csharp
Image<Bgr, byte> img = new Image<Bgr, byte>("board.jpg");
imageViewer1.SetImage(img.ToBitmap());
```

### 像素排布对照表

| OpenCV 类型 | `CvPixelLayout` | 说明 |
|---|---|---|
| `CV_8UC1` | `Gray8` | 自动附加灰度调色板 |
| `CV_8UC3`（默认） | `Bgr24` | 自动完成 BGR → RGB 交换 |
| `CV_8UC3`（已转 RGB） | `Rgb24` | 不做通道交换 |
| `CV_8UC4` | `Bgra32` | 第 4 通道强制置为 255（不透明） |

> **注意**：`CV_16U`、`CV_32F` 等类型需先在 OpenCV 侧 `convertTo(CV_8U)` 归一化，
> 本控件只处理 8 位数据。

## 五、坐标系

控件维护两套坐标，务必区分：

- **图像坐标**：图形存储与业务计算使用的坐标，原点在图像左上角，单位为图像像素。
  `IGeometryShape` 的所有几何属性都是图像坐标。
- **控件坐标**：屏幕像素，用于鼠标输入与绘制。

换算方法：

```csharp
PointF ctrl = imageViewer1.ImageToControl(new PointF(100, 50));
PointF img  = imageViewer1.ControlToImage(new PointF(300, 200));
```

底层公式：

```
control = image * Zoom + Offset
image   = (control - Offset) / Zoom
```

### 右下角 HUD

控件右下角实时显示鼠标所在的**图像坐标**与像素值，默认开启，无需额外接线：

| 图像类型 | 显示内容 |
|---|---|
| 灰度图 | `X: 412.5    Y: 238.0` ／ `Gray: 173` |
| 彩色图 | `X: 412.5    Y: 238.0` ／ `Color: (201, 96, 44)` |

- **灰度判定**：`Format16bppGrayScale`，或调色板全部为灰阶的 `Format8bppIndexed`。
  由 `CvInterop` 从 `CV_8UC1` 转换来的图正是后者，会自动识别为灰度。
- 左侧有个小色块，直观预览当前像素颜色。
- 鼠标移出图像范围时，像素值显示 `--`，坐标仍然照常显示。
- 关闭：`imageViewer1.ShowHud = false;`
- 想改成自己的显示逻辑（比如加缩放、加测量值）：订阅 `MouseImageMove` 事件自己画，
  把内置 HUD 关掉即可。

## 六、性能与常见问题

**Q：4K 甚至 8000×4000 的大图会卡吗？**
控件做了三层优化，正常情况下不会：

1. **静态内容缓存**——背景、图像、像素网格渲染在缓存层里，只有图像 / 缩放 / 平移 /
   控件尺寸变化时才重建。鼠标移动、拖拽图形只重绘图形层和鼠标相关层。
2. **只渲染可见区域**——放大或 1:1 时只绘制屏幕可见范围对应的源矩形，与图像总尺寸无关。
3. **图像金字塔**——可见源区域超过 200 万像素时，改用金字塔中「分辨率最贴近屏幕需求」
   的那一层来采样。金字塔只在换图时生成一次（逐级 1/2 下采样，总代价约为原图的 1/3），
   缩放时只是换一层，不再重新缩整图，因此滚轮连续缩放、拖拽平移都很流畅。

另外，**索引色图像（8bpp 灰度很常见）在 GDI+ 中缩放绘制极慢**（每个像素都要查调色板），
控件会在载入时自动转成 24bpp。灰度判定在转换**之前**完成并缓存，
所以右下角 HUD 仍然正确显示 `Gray` 而不是 RGB。

如仍觉得慢，可关闭像素网格：`viewer.Options.ShowPixelGrid = false`。

**Q：改了 Options 的背景色 / 网格色，为什么界面没变？**
这些属于缓存层内容，需要调用 `viewer.InvalidateImageLayer()` 强制重建，
只调用 `Invalidate()` 不够。

**Q：图像显示全黑？**
灰度图（`CV_8UC1`）必须用 `CvPixelLayout.Gray8`，`CvInterop` 会自动附加灰度调色板。
若用 `Bgr24` 去解析单通道数据，会得到错误结果。

**Q：颜色偏蓝/偏红？**
通道顺序问题。OpenCV 默认是 BGR，用 `Bgr24`；若你的数据已转成 RGB，改用 `Rgb24`。

**Q：切换图像后内存上涨？**
`OwnsImage` 默认为 `true`，切换图像时控件会自动 `Dispose` 旧图。
若你的 `Bitmap` 在别处还要用，请设为 `viewer.OwnsImage = false`，自行管理生命周期。

**Q：图形线宽随缩放变粗？**
不会。`LineWidth` 以屏幕像素为单位，缩放时视觉宽度恒定。

**Q：如何限制缩放范围？**
`Viewport.MinZoom`（0.01）与 `Viewport.MaxZoom`（256）是 `const`。
如需改动，调整 `Viewport.cs` 中的常量后重新编译。

**Q：如何禁止用户编辑某个图形？**
```csharp
shape.IsEditable = false;   // 不可选中、不可拖拽，但仍会绘制
shape.Visible = false;      // 完全不绘制
```

**Q：图形被代码修改后界面不刷新？**
集合自带变更通知会重绘，但**直接修改图形几何属性**（如 `circle.Radius = 50`）不会自动触发。
手动调用一次：

```csharp
imageViewer1.Shapes.NotifyChanged();
```

## 七、典型业务流程

```
相机采集（OpenCV Mat）
      ↓  SetCvImage(...)
控件显示
      ↓  用户拖拽绘制 ROI
ShapeCreated 事件
      ↓  CvInterop.ToCvParameterString(shape)
拿到 center / size / angle
      ↓
传给算法模块做定位、测量、识别
```
