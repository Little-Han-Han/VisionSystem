> 对应节点：`异常检测 AnomalyDetect`（模块包 `VisionPlatform.Modules`）
> 原生实现：`src/VisionAlgo.Native/src/algo/algo_anomaly.cpp`
> 方案背景与选型对比：见 [无监督缺陷检测技术方案.md](无监督缺陷检测技术方案.md)

## 1. 固定目录约定

模型**不选路径**，一律放在：

```
<程序目录>\Models\Anomaly\<模型名>\
```

`<模型名>` 就是参数里存的值、也是下拉框的 Key。换台机器只要把整个 `Models\Anomaly` 拷过去就能用，
不会出现"这个流程指向 D:\临时\xx"的配置。目录由 `AppPaths.Ensure()` 自动创建，
规则真源在 `VisionPlatform.Framework/Modules/AnomalyModelCatalog.cs`。

### PaDiM（本库可训练）

| 文件 | 必需 | 说明 |
|---|---|---|
| `model.json` | 是 | 元信息（见下节），界面只读它就能列出模型，不必加载权重 |
| `padim.bin` | 是 | 逐位置均值 + Cholesky 因子 + 有效维数选择表 |
| `extractor.xml` / `.bin` | 否 | 特征提取器 IR。没有就用**内置描述子**（开箱即用） |

`padim.bin` 布局（小端）：

```
char[8]  "VAPADIM1"
int[6]   dim, grid_w, grid_h, src_dim, patch, samples
float    threshold
int      selN  (== dim)
int[selN] sel   ← 保留维对原始通道的下标（训练收尾会按样本数收缩维数）
float[grid_w*grid_h*dim]          mean
float[grid_w*grid_h*dim*dim]      chol（下三角，按行存）
```

### EfficientAD（只推理）

| 文件 | 必需 | 说明 |
|---|---|---|
| `model.json` | 是 | `kind = 1` |
| `teacher.xml` / `teacher.bin` | 是 | 教师网络 |
| `student.xml` / `student.bin` | 是 | 学生网络（与教师同形状输出） |
| `ae.xml` / `ae.bin` | 否 | 自编码器（全局/逻辑异常分支）；缺失时只用 ST 分支 |
| `ead_norm.bin` | 否 | 归一化统计，缺省按 `st_mean=0, st_std=1, ae_mean=0, ae_std=1` |

### model.json 字段

```json
{
  "kind": 0,              // 0 = PaDiM, 1 = EfficientAD
  "feat": 0,              // 0 = 内置描述子, 1 = OpenVINO 特征提取器
  "input": 256,           // 分析分辨率（PaDiM 内置描述子用）
  "patch": 8,             // 描述子 patch 边长 → 网格 = input/patch
  "grid_w": 32, "grid_h": 32,
  "dim": 5,               // 有效维数（可能小于 src_dim，见 §3）
  "src_dim": 15,          // 原始维数（内置描述子固定 15，IR 时为通道数）
  "samples": 16,          // 参与训练的 OK 张数
  "threshold": 8.976,     // 原始分阈值（max_score = raw / threshold）
  "extractor": "",        // feat=1 时为 "extractor.xml"
  "algo": "PaDiM"
}
```

## 2. 训练（界面操作）

参数面板里点 **「训练 / 标注样本…」** 打开窗体：

1. **添加图片 / 添加文件夹**：把同一工位、同一光照下的 OK 图一次加进来（建议 ≥ 20 张，
   30~50 张最稳）。有已知 NG 也一起加进来，只用来**验证**，不参与拟合。
2. **标 OK / NG**：缩略图墙上多选后点「标 OK」「标 NG」，或双击逐张循环（未标→OK→NG→未标），
   快捷键 `1/O`、`2/N`、`0`。当前张标完自动跳下一张。
3. **框 ROI**（可选但强烈建议）：只把"可能出缺陷的那块表面"框进来。ROI 越小，
   同样的缺陷占比越大，灵敏度越高；同时把"肯定正常"的区域（夹具、背景）排除掉，假阳性明显下降。
4. **分析分辨率**：128 / 192 / 256 / 320。分辨率越高越能抓细划痕，但同样的 patch 网格下
   单 patch 覆盖的实际尺寸越小、越容易被噪声带动。细划痕用 320，大面积脏污/缺料用 192。
5. **训练** → 落盘到 `Models\Anomaly\<模型名>\`，并把结果摘要（张数 / 网格 / d / 阈值）打在日志框。
6. **用当前模型验证**：逐张回验、算混淆矩阵（检出率 / 过杀率）。过杀高就调"判定阈值"或缩小 ROI。

阈值也可以直接在**节点参数**里改（「判定阈值」= 原始分，留 0 表示用模型自带的）：
节点里的值只影响这一个节点，不动模型文件。

> 样本清单（`samples.txt`）与 OK/NG 标注会跟着窗体保存，下次打开自动恢复，不用重新标。

## 3. 阈值是怎么来的（以及为什么会"偏松"）

`max_score`、`mean_score`、热图上的每个数值都是 **`raw / threshold`**，**1.0 就是阈值**。
换模型、重训、改阈值都不改变读数习惯。

训练收尾做三件事：

1. **维数收缩**：每位置要拟合 `d×d` 协方差，样本数 `n` 只比 `d` 多一点点时，
   样本协方差在新样本的偏离方向上被系统性低估，马氏距离被放大（现场表现：
   训练集全过、新 OK 图整幅判 NG）。因此 `d ≤ n/3`（下限 2），压掉的维写进 `sel`。
2. **k 折留出校准**：把样本切 4 折，轮流留一折出来打分，用这些"没见过"的分数定阈值，
   再乘 1.5 的余量。**自评分数只作诊断显示**（摘要里的「自评」）。
3. **卡方近似兜底**：样本太多/维太高导致无法保留样本时，按 `1 + 6√(2/d)` 给阈值。

所以**样本越多，阈值越紧、灵敏度越高**；只给 5 张 OK 图训练出来的模型一定是"偏保守"的。

## 4. EfficientAD 导出（PyTorch → OpenVINO）

本库不做 EfficientAD 训练（学生网络要反向传播）。流程：

```bash
# 1) 训练：官方仓库 anomaly-detection 里的 efficientad 训练脚本，
#    产出 teacher.pt / student.pt / autoencoder.pt（或单个 checkpoint）
# 2) 导出 ONNX（输入名无关，形状必须 [1,3,H,W]，建议 H=W=256）
python export_onnx.py --ckpt teacher.pt --out teacher.onnx
python export_onnx.py --ckpt student.pt --out student.onnx
python export_onnx.py --ckpt autoencoder.pt --out ae.onnx
# 3) ONNX → OpenVINO IR
ovc teacher.onnx --output_model teacher.xml
ovc student.onnx --output_model student.xml
ovc ae.onnx      --output_model ae.xml
# 4) 放到固定目录，补 model.json（kind=1）
#    建议顺便把归一化统计写成 ead_norm.bin：float[4] = st_mean, st_std, ae_mean, ae_std
```

约定与校验：

- 输入统一按 **BGR → RGB、/255、NCHW** 预处理（原生侧 `MakeBlob`）。
- `teacher` 与 `student` 的输出形状必须**完全一致**；不一致直接报"学生与教师输出不一致"。
- 融合方式：`0.5 × (ST 误差归一化) + 0.5 × (AE 重建误差归一化)`，AE 缺失时只用前者。
- 输出通道维序按"谁最小"自动判定（`[1,C,h,w]` 或 `[1,h,w,C]` 都支持）。

## 5. 现场排障

| 现象 | 先看什么 | 处理 |
|---|---|---|
| OK 图也大面积红 | 热图面积占比接近 1 | 缩小 ROI（把背景/夹具排除）；换更多样的 OK 图重训 |
| OK 图零星红点 | 面积占比 < 5% | 调大「最小缺陷面积」，或把「判定阈值」提高一点 |
| 细划痕漏检 | 最大分 < 1 但热图上有淡色痕迹 | 提高分析分辨率；缩小 ROI；「最小缺陷面积」调小 |
| 分数读数看不懂 | — | 一切都是"阈值倍数"，1.0 = 阈值；原始值看节点结果里的 `raw_max` |
| 换模型后还是老结果 | 模型是否重训过 | 缓存键带 `model.json` 修改时间，重训即失效；仍异常就重启流程 |

诊断开关：设环境变量 **`VA_ANOM_DEBUG=1`**，推理时会把"最大分位置的逐维
`x / μ / σ / z` 与贡献占比"打到 stderr：

- 某一维占 60% 以上 → 该维方差被低估（特征不稳，考虑换分辨率/缩小 ROI）；
- 各维占比均匀但总分很高 → 整体尺度问题（样本太少，或该位置本来就有结构变化）。

## 6. 与节点的对接

| 端子 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `Image` | 入 | 图像 | 待检图 |
| `Pose` | 入 | 位姿 | 可选，接模板/形状匹配/位置修正，检测区域随工件移动 |
| `Image` | 出 | 图像 | 热图（相对阈值刻度，叠加显示用） |
| `Score` | 出 | 数值 | 最大异常分（1.0 = 阈值） |
| `Area` | 出 | 数值 | 面积占比（超阈值像素 / ROI 面积） |
| `Count` | 出 | 数值 | 缺陷连通域个数（只算够「最小缺陷面积」的） |
| `Box` | 出 | 矩形 | 最大缺陷框 |
| `Point` | 出 | 点 | 最大分点位 |

判定：`max_score ≤ 1.0` 且 `Area ≤ 面积上限`（面积上限留 0 表示不判）。
需要回传给 PLC 时，坐标/面积用 `SendData` 的 `MbMap`（`PosX:30:Int32` 之类），
`Score` 建议放大 100 倍后按 `Int32` 传，避免 PLC 侧浮点。
