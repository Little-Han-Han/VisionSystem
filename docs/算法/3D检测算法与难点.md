# 3D 检测所需算法与难点（胶路、焊锡、划痕）

> 文档目标：梳理工业 3D 视觉检测的完整算法链、关键难点和场景化方案，供平台选型与节点设计参考。
> 资料口径：商用部分只引用厂商官方页面/手册能支撑的能力，不推断 proprietary 算法。
> 整理日期：2026-11-23。

## 1. 结论先行

1. **3D 的价值是高度、体积、截面和空间位姿，不是替代所有 2D。** 只需有无、计数、字符、颜色、平面印刷质量时，2D + 结构化打光更划算；只有需要高度/体积/共面性/路径空间偏差时才值得上 3D [C7]。
2. **算法链不是“有个深度图就行”。** 完整链路为：成像选型 → 标定 → 预处理/点云质量掩码 → 几何建模 → 检测/匹配 → 公差判定/SPC。链路上任一环不稳，后面的 AI 也救不回来。
3. **胶路检测本质是在线剖面计量 + 路径比对**：核心输出是宽度、高度、截面积/体积、横向偏位、连续性；难点是湿胶反光、喷头运动、手眼标定误差 [P11][C5][C8]。
4. **焊锡/锡膏检测要分层看表面与内部**：3D SPI/激光轮廓看高度、体积、桥连和翘曲；内部空洞、BGA 底部必须 X-ray/CT，3D 表面测量看不到 [P9][C11]。
5. **划痕是几何弱信号**：大视场商用 3D 点距通常 >0.1 mm，微米级划痕主要靠 2D 明暗场/光度立体检出；3D 输出应表述为“异常置信度/相对深度”，不要包装成绝对深度真值 [C4][C5][P6][P8]。

## 2. 3D 成像方式选型

| 成像方式 | 原理 | 适用尺度 | 材质适应性 | 节拍特点 | 典型商用参考 |
|---|---|---|---|---|---|
| 激光三角 / 线激光轮廓 | 激光线投影，相机斜视，按三角关系求剖面高度，运动扫描成 3D | 小—中视场；单头最宽可达 720 mm [C5] | 蓝激光受颜色/温度影响较小；焊后光泽件有专用光学型号 [C4][C5] | 高速剖面：LJ-V7000 最高 64 kHz [C4]；Ranger3 最高 69 kHz profiles [C6] | Keyence LJ-X/LJ-V [C4][C5]、SICK Ranger3 [C6]、Cognex 3D-L4000 [C2] |
| 结构光 / 条纹投影 | 全场编码投影，解码/相位展开后三角重建 | 小视场高精度（如 SPI 20×20 mm [P9]）到中型全场 | 反光/高光敏感；蓝光窄带滤光可改善 [C4][P7] | 多帧相移受节拍限制，单次/FTP 可抗运动 [P7][P8] | Cognex 3D-A [C1]、Photoneo PhoXi [C3]、GOM/ZEISS 光学 3D [C10] |
| ToF | 光往返时间，快照深度 | 大视场、工作距离 > 0.5 m [C7] | 受反射率影响 | 快照，抗运动模糊 [C7][P8] | SICK 2D/3D 对比资料 [C7] |
| 双目 / 多目立体 | 视差重建，可加投影图案 | 大视场、户外/物流 | 弱纹理需辅助投影 [C7][C1] | 快照 | HALCON stereo / surface-based 3D matching [C11] |
| 光度立体 | ≥3 个已知方向光源逐次成像，解算法向再积分高度 | 平面/缓曲面、微起伏 | 适合漫反射；金属高光、玻璃透明差 [P12] | 多次曝光，静态/慢速 | Woodham 原始方法 [P12] |
| 白光干涉 / 色散共焦 | 低相干干涉或轴向色散编码 | 微纳表面、粗糙度、透明多层 | 干涉对振动敏感，共焦可测曲面/透明层 [P13] | 慢，适合抽检 | 微纳光学计量综述 [P13] |

### 2.1 不要上 3D 的场景

- 只需**有无、计数、字符/条码、颜色**，且对比度充足：2D 足够。
- 平面标签、印刷质量、高对比外观分类：2D + 多角度明场/暗场更经济。
- 镜面/透明件只判“缺陷存在性”、无法喷涂：2D 明暗场或光度立体（2.5D）优先。
- 焊点内部空洞、桥连、BGA 底部：X-ray/CT，不是表面 3D。
- 大视场微米级划痕：3D 点距不够，使用 2D 明暗场 + AI/光度立体。
- 极高精度静态抽检：CMM/白光干涉，不上在线 3D [C10][P13][P14]。

## 3. 算法链逐项列出

### 3.1 标定

| 项目 | 要做的事 | 关键方法/工具 | 风险 |
|---|---|---|---|
| 相机内参/畸变 | 焦距、主点、畸变系数，像素→射线 | 标定板自标定、畸变校正 | 视场边缘外推误差 |
| 投影仪/激光标定 | 结构光相位→高度、激光平面方程 | 球体标定、平面平移标定、光条中心提取 [P5] | 温漂、振动、镜头更换后失效 |
| 外参/手眼 | 传感器坐标→机器人/工作台坐标 | HALCON Hand-Eye Calibration [C12] | 小角度偏差会放大成毫米级轨迹误差 [P11] |
| 像素→物理单位 | 深度图转 mm/µm | 标定文件 + 尺度因子 | 混用不同标定文件导致整批误判 |
| 周期复检 | 验收与再验证 | ISO 10360-13（光学 3D CMS）[P14]、VDI/VDE 2634（待核实原文） | 只看出厂精度、不做现场复检是常见坑 |

### 3.2 预处理与点云质量

1. **深度图滤波**：中值/双边/高斯平滑，抑制散斑与孤立噪声；需保留边缘。
2. **离群点剔除**：统计离群、半径离群；反光区域常产生飞点。
3. **空洞标记与置信度掩码**：阴影、遮挡、低反射率区域不参与判定或单独降级。
4. **下采样**：体素栅格可降低计算量，但可能抹掉细边缘和小凹坑 [P11]。
5. **配准/拼接**：ICP 是基础方法 [P3]，point-to-point / point-to-plane 变体各有收敛特性 [P4]；多相机 360° 拼接需全局一致性约束 [C8]。
6. **剖面对齐**：线激光场景在 X/Z/θ 方向校正振动、偏心与弯曲 [C5]。

### 3.3 几何建模

- **数据形态**：点云、深度图、网格；线激光天然是 2D 剖面序列。
- **基元拟合**：平面、圆柱、球、直线；用于基准面、焊盘、胶面、安装面。
- **法线与曲率**：用于凹坑、毛刺、焊点形貌异常；高曲率/非光滑区域会失效 [P6]。
- **特征描述**：3D shape-based matching 可用 CAD 模型、轮廓或圆/方等形状特征定位任意摆放物体；surface-based 3D matching 结合多视角立体 [C11]。
- **参考模型**：示教模板、CAD 理论模型或统计正常模型（OK 样本均值/方差）。

### 3.4 检测与判定

| 检测目标 | 算法 | 输出 |
|---|---|---|
| 位姿/装配 | 3D shape-based matching、ICP、特征配准 | 6DoF 位姿、偏差向量 |
| 尺寸/形貌 | 剖面高度、宽度、面积、体积、平面度 | 物理量 + 公差判定 |
| 表面异常 | 深度高通、法线/曲率异常、3D-AD | 异常热图/分数 |
| 路径类 | 中心线提取、样条拟合、路径偏差、工程上常用 DTW 对齐 | 偏位、断胶、连续性 |
| 趋势 | SPC、Cpk、均值/方差漂移 | 工艺趋势与报警 |

## 4. 典型场景方案

### 4.1 胶路 / 涂胶 / 密封胶

**推荐算法组合**

1. 喷头附近线激光或 360° 激光三角环采集剖面 [P11]。
2. 剖面对齐：消除机器人振动、偏心、胶面弯曲 [C5]。
3. 每帧剖面提取：胶宽、胶高、截面积、谷底、边缘角度。
4. 沿示教路径做剖面序列比对（工程上可用 DTW 对齐，非厂商公开算法）。
5. 阈值 + SPC：断胶、溢胶、塌胶、爬墙、颈缩、横向偏位、体积偏差。
6. 闭环补偿：间隙修补、Z 高跟踪、横向修正 [P11]。

**输出量**：胶宽、胶高、截面积/体积、中心线偏位、连续性、Cpk/趋势 [C5][P11]。

**主要失效模式**

- 湿胶/抛光金属反光导致点云噪声，必要时喷涂但会带来厚度偏置 [P11]。
- 手眼标定小角度误差导致毫米级沉积偏差 [P11]。
- 体素下采样过强，颈缩/细断胶被平滑掉 [P11]。
- 只看 2D 宽度无法区分“宽而扁”和“窄而高”，塌胶漏检。
- 机器人加减速导致胶量堆积，需按速度做 Section 面积归一化。

**置信度**：中高。胶路是 3D 最适合的场景之一，但需现场手眼与工艺速度标定；公开案例给出高度/宽度/位置重复性误差 0.013 / 0.032 / 0.030 mm、Cpk ≥ 1.33 [C9]，属于特定案例，不能当通用指标。

### 4.2 焊锡 / 焊点 / 锡膏（SPI/AOI）

**推荐算法组合**

1. 印刷后 3D SPI：结构光相移求高度/体积，融合 2D 图像判桥连与污染 [P9]。
2. 回流后 3D AOI/激光轮廓：焊点高度、共面性、翘曲、表面形貌。
3. 内部缺陷：X-ray/CT 检空洞、桥连、BGA 底部 [C10]。
4. 判定：焊盘局部基准面 + 焊点区域分割 + 体积/高度/形状阈值 + SPC。

**输出量**：锡膏体积、高度、面积、桥连、少锡/虚焊风险、焊点共面性、翘曲量。

**主要失效模式**

- 锡膏高反光导致像素过饱和，破坏相位图与 3D 重建 [P15]。
- 焊后表面光泽/氧化、阴影与遮挡。
- 文献系统水平：20×20 mm 区域约 2 s、平均高度标准差 3 µm [P9]；不要据此推断所有设备指标。
- 3D 只看表面，内部空洞必须 X-ray/CT。
- 基准面未随板翘曲动态修正，会把板弯误判为少锡/多锡。

**置信度**：中。表面几何量可靠；虚焊/内部空洞的因果判定需多模态或电测验证。

### 4.3 划痕 / 表面微缺陷

**推荐算法组合**

1. 先用 2D 明暗场/低角度光/偏振成像获得高对比 2D 证据。
2. 光度立体获取法向场，增强微起伏方向性 [P12]。
3. 3D 深度图做高通、法线/曲率异常、局部平面残差。
4. 3D-AD：MVTec 3D-AD、deep geometric descriptors、depth simulation 可作为算法参考 [P6][P7][P8]。
5. 2D 与 3D 融合判定：3D 给“是否有几何异常”的置信度，2D 给“是否可见”的证据。

**输出量**：法向/深度偏差图、异常分数、缺陷长宽、相对深度；微米级绝对深度需白光干涉/共焦复核 [P13]。

**主要失效模式**

- 大视场点距过粗：PhoXi L 点距 0.524 mm、时间噪声 0.19 mm；M 为 0.286 mm / 0.1 mm [C3]，不足以直接量微米级划痕。
- 高曲率、非光滑区域的法线/曲率方法失效 [P6]。
- 反光/透明材质相位误差与伪影。
- 3D-AD 任务仍有明显提升空间，不能把 2D 的 99% AUROC 直接迁移到 3D [P6][P7]。

**置信度**：中低。建议把 3D 作为辅助通道，不要把微米级划痕的 OK/NG 完全交给在线 3D。

## 5. 难点逐项：为什么难 + 缓解措施

| 难点 | 为什么难 | 缓解措施 |
|---|---|---|
| 反光/透明/黑色材质 | 偏离漫反射与“cooperative surface”假设，ISO 10360-13 明确限定表面条件 [P14] | 蓝激光 + 窄带滤光 [C4]、偏振/HDR、喷涂显像剂（注意厚度偏置）[P11]、改共焦/干涉 [P13] |
| 镜面与多重反射 | 结构光相位误差、伪影 [P7] | 多频/多姿态冗余、相位偏折术（具体论文待核实）、降级为 2D 明暗场 |
| 边缘/阴影/空洞 | 遮挡和不连续表面导致相位/点云缺失 | 多视角冗余、多频相位展开、置信度掩码、不参与判定 |
| 运动模糊与振动 | 多帧相移对运动敏感 [P7][P8] | 单次/FTP/ToF 快照、剖面对齐 [C5]、机械减振 |
| 点云配准漂移 | ICP 依赖初值、易陷局部极小 [P3][P4] | 特征粗配准 + ICP 精配准、标定球/球杆周期复核 [P14] |
| 跨设备/批次迁移 | 内参外参、畸变、温漂随设备变化 | 统一标定板与流程、换设备强制重标定、验收/复检记录 [C12][P14] |
| 分辨率与视场矛盾 | 固定像元下视场越大点距越粗 [C3][C5] | 按最小特征选点距，必要时多传感器/ROI 高速模式 |
| 节拍与数据量 | 百万点/秒量级数据 [C3] | AOI 降采样、线激光剖面流式处理、GPU/嵌入式流水线 |
| 真值获取与评价 | 设备精度 ≠ 零件公差，表面条件影响结果 | CMM [C10]、ISO 10360-13 [P14]、白光干涉/切片 [P13]、建立 MSA/不确定度预算 |

## 8. 对本项目（VisionSystem）的落地建议

1. **先做 2.5D，再接真 3D**：现有 2D/3D 共用 ImageViewer 已支持点云显示；新增线激光剖面采集后，可先复用剖面/轮廓节点。
2. **节点拆分**：`PointCloudSource` → `CloudFilter` → `CloudRegister` → `CloudFeature` → `CloudCompare` → `CloudResult`，不要把所有算法塞进一个节点。
3. **结果口径**：距离/高度/体积用 mm³/mm，置信度单独字段；不能把点云异常分数当物理量。
4. **标定文件纳入配方**：与 `recipe.json` 同目录保存标定版本，模板戳中加入标定文件 hash，避免换标定后仍用旧模板。
5. **场景优先级**：胶路剖面 > 锡膏高度/体积 > 划痕置信度；划痕只做 2D+3D 融合辅助，不承诺微米级绝对深度。
