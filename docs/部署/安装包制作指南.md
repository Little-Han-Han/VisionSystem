# 安装包（EXE 安装器）制作指南

> 目标：把 `dist\VisionPlatform` 便携包做成一个**双击即可安装**的 `VisionPlatform-x.y.z-setup.exe`，
> 交给现场/客户在自己机器上安装，并支持**升级不丢配置**、**卸载可保留配方**。
>
> 本文只给方案与步骤，**尚未落地任何安装脚本**。落地时按第 4～6 节照做即可（约 1 小时）。

---

## 1. 先认清现状：为什么不能"直接压缩发过去"

当前发布方式是 **便携部署**（`publish.bat` → `dist\VisionPlatform`），它的设计前提写在 `DEPLOY.txt` 里：

| 前提 | 含义 | 对安装包的影响 |
|---|---|---|
| **不要放 Program Files** | 程序运行时要写 `Config\`、`Logs\`、`Recipes\`、`Templates\` | 装到 `Program Files` 会因 UAC 无法写入 → **必须选可写目录，或重定向数据目录** |
| 依赖 app-local | `thirdparty\{opencv,openvino,sqlite}\` + `thirdparty\vcruntime\`（VC++ 运行库） | 不需要装 VC++ Redist，安装包只需**原样搬运** |
| 需要 .NET Framework 4.8 | Win10 1903+ 自带；Win7/8.1 需另装 | 安装器要做**框架检测**并提示 |
| 数据与二进制分离 | 升级只换 `exe/DLL/thirdparty`，保留 `Config/Recipes/Templates` | 安装器**不能把空数据目录当"文件"覆盖**，要用"目录不存在才创建" |

**体积参考**（当前 Release）：

| 内容 | 约 |
|---|---|
| exe + 自家 DLL | 20 MB |
| `thirdparty\{opencv,openvino,sqlite,vcruntime}` | 120 MB |
| `models\`（YOLO / OCR-DL，可选） | 137 MB |

→ 不含模型 ≈ **140 MB**，含模型 ≈ **280 MB**。安装包压缩后约 60～130 MB。

## 2. 先定一个关键决策：装到哪里

这一条决定了安装脚本怎么写，必须先定：

| 方案 | 安装目录 | 权限 | 优点 | 缺点 |
|---|---|---|---|---|
| **A. 非系统盘（推荐产线）** | `D:\VisionPlatform` | 安装需管理员，运行不需要 | 与现有便携包**完全一致**，`publish.bat` 产物能直接比对；数据就在安装目录，现场好找 | 需管理员安装 |
| B. Program Files + 数据重定向 | `C:\Program Files\VisionPlatform` | 运行不需要（数据在 ProgramData） | 符合 Windows 规范 | **要改代码**：`AppPaths` 的数据根改到 `%ProgramData%\VisionPlatform`，并处理老数据迁移 |
| C. 每用户安装 | `%LOCALAPPDATA%\VisionPlatform` | **全程免管理员** | 装完即用，无 UAC | 多用户各一份；现场不易找 |

> **建议先做 A**：零代码改动，今天就能出包。将来要过安全审计再考虑 B（工作量约 1 天，含迁移与回归）。

本文后续脚本按 **方案 A** 写，并在第 7 节给出 B 的改法要点。

## 3. 方案选型：用哪个工具做安装器

| 工具 | 学习成本 | 产物 | 中文界面 | 静默安装 | 适合场景 |
|---|---|---|---|---|---|
| **Inno Setup 6**（推荐） | 低（一个 `.iss` 文本脚本） | 单个 `setup.exe`（约 2.5 MB 引导 + 内嵌压缩包） | ✅ 需加语言文件 | ✅ `/VERYSILENT` | 本项目：一次写好，长期复用 |
| WiX Toolset（MSI） | 中高（XML + 组件/GUID 规则） | `.msi` | ✅ | ✅ | 需要域部署 / 组策略 / 软件分发系统 |
| NSIS | 中（脚本语言） | `setup.exe` | ✅ | ✅ | 需要高度定制安装逻辑 |
| MSIX | 高（需签名证书、打包工程） | `.msix` | ✅ | ✅ | 上架商店 / 现代部署，本项目不适用 |
| 7-Zip SFX 自解压 | 极低 | `.exe` 自解压 | ❌ | 半支持 | 临时应急，无安装/卸载/升级概念 |

**选 Inno Setup 的理由**：单文件脚本可入库、天然支持"同 `AppId` 覆盖升级"、能检测 .NET 版本与运行中进程、卸载可保留数据，且免费可商用。

## 4. 打包前的一次性准备

### 4.1 装工具

1. 下载 **Inno Setup 6**：<https://jrsoftware.org/isdl.php>（选 `innosetup-6.x.x.exe`，默认安装即可）。
2. 安装后确认命令行编译器存在：
   ```
   "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
   ```
3. （可选）中文向导界面：Inno 安装目录下 `Languages\ChineseSimplified.isl` 可能缺失，
   可从 Inno 官方仓库的非官方语言包补一个，放到同目录。

### 4.2 在仓库里加两个文件（落地时才建）

```
installer\
    setup.iss            # 安装脚本（入库）
    app.ico              # 安装器与快捷方式图标（可从 assets\app.ico 复制）
```

### 4.3 每次出包的固定顺序

```bat
version.bat 1.0.11.0      :: ① 先定版本（写 SharedVersion.cs / README）
build.bat Release         :: ② 编译
publish.bat               :: ③ 生成干净便携包 dist\VisionPlatform
                          ::    需要深度学习模型时：publish.bat --with-models
ISCC installer\setup.iss  :: ④ 生成安装包
```

> 顺序不能颠倒：安装脚本从 `dist\VisionPlatform\VisionPlatform.exe` **读取文件版本号**作为安装包版本，
> 所以必须先 `version.bat` 再 `publish.bat`。

## 5. 安装脚本（Inno Setup）完整模板

`installer\setup.iss` —— 直接可用，逐段注释说明为什么这么写。

```ini
; ============================================================================
;  VisionPlatform 安装脚本（Inno Setup 6）
;  用法：在仓库根目录执行  ISCC installer\setup.iss
;  产物：installer\Output\VisionPlatform-<版本>-setup.exe
; ============================================================================

#define AppName        "VisionPlatform"
#define AppPublisher   "（填公司名）"
#define SourceDir      "..\dist\VisionPlatform"

; 【版本号零维护】直接读 exe 的文件版本（由 version.bat 写入 SharedVersion.cs）
;   好处：不再手改安装脚本，也绝不会出现"程序 1.0.10.1 / 安装包 1.0.9"这种错位
#define AppVersion     GetFileVersion(SourceDir + "\VisionPlatform.exe")

[Setup]
; AppId 一经发布不可再改：升级安装靠它识别"这是同一个产品"，改了会变成两个程序并存
AppId={{8F3C2A74-6B1D-4E52-9C7A-2D5E1B0F9A31}
AppName={#AppName}
AppVersion={#AppVersion}
AppVerName={#AppName} {#AppVersion}
AppPublisher={#AppPublisher}
VersionInfoVersion={#AppVersion}
VersionInfoDescription={#AppName} 安装程序

; ---- 安装位置（方案 A：非系统盘，数据与程序同目录，最简单）----
DefaultDirName=D:\{#AppName}
DefaultGroupName={#AppName}
; 允许用户改目录；若坚持固定目录，改成 DisableDirPage=yes
AllowNoIcons=yes
PrivilegesRequired=admin

; ---- 产物 ----
OutputDir=Output
OutputBaseFilename={#AppName}-{#AppVersion}-setup
SetupIconFile=app.ico
UninstallDisplayIcon={app}\VisionPlatform.exe
Compression=lzma2/max
SolidCompression=yes
WizardStyle=modern

; ---- 中文化（语言文件缺失时回退英文，不影响功能）----
ShowLanguageDialog=no

; ---- 升级时自动关掉正在运行的程序（否则文件被占用、覆盖失败）----
CloseApplications=yes
RestartApplications=no

[Languages]
Name: "cn"; MessagesFile: "compiler:Languages\ChineseSimplified.isl"
Name: "en"; MessagesFile: "compiler:Default.isl"

[Tasks]
Name: "desktopicon"; Description: "创建桌面快捷方式"; GroupDescription: "附加任务:"
Name: "quicklaunchicon"; Description: "创建快速启动快捷方式"; Flags: unchecked

[Files]
; ① 主程序与自家 DLL（publish.bat 已剔除 pdb/exp/lib）
Source: "{#SourceDir}\*.exe"; DestDir: "{app}"; Flags: ignoreversion
Source: "{#SourceDir}\*.dll"; DestDir: "{app}"; Flags: ignoreversion

; ② 第三方原生库 —— 必须整目录递归，目录层级不能变（NativeDllPath 按相对路径拼 PATH）
Source: "{#SourceDir}\thirdparty\*"; DestDir: "{app}\thirdparty"; Flags: ignoreversion recursesubdirs createallsubdirs

; ③ 深度学习模型（只有 publish.bat --with-models 才存在）
Source: "{#SourceDir}\models\*"; DestDir: "{app}\models"; Flags: ignoreversion recursesubdirs createallsubdirs skipifsourcedoesntexist

; ④ 部署说明
Source: "{#SourceDir}\DEPLOY.txt"; DestDir: "{app}"; Flags: ignoreversion

[Icons]
Name: "{group}\{#AppName}"; Filename: "{app}\VisionPlatform.exe"
Name: "{group}\卸载 {#AppName}"; Filename: "{uninstallexe}"
Name: "{autodesktop}\{#AppName}"; Filename: "{app}\VisionPlatform.exe"; Tasks: desktopicon

[Dirs]
; 【关键】数据目录只"确保存在"，绝不打包空目录：
;   - 用 uninsneveruninstall 让卸载**保留**现场配方与配置
;   - 用 Permissions 给 Users 写权限（即使用户把程序装到 C:\ 根目录也能写）
Name: "{app}\Config";        Permissions: users-modify; Flags: uninsneveruninstall
Name: "{app}\Recipes";       Permissions: users-modify; Flags: uninsneveruninstall
Name: "{app}\Templates";     Permissions: users-modify; Flags: uninsneveruninstall
Name: "{app}\Images";        Permissions: users-modify; Flags: uninsneveruninstall
Name: "{app}\Calibrations";  Permissions: users-modify; Flags: uninsneveruninstall
Name: "{app}\OCRModel";      Permissions: users-modify; Flags: uninsneveruninstall
Name: "{app}\Logs";          Permissions: users-modify

[Run]
Filename: "{app}\VisionPlatform.exe"; Description: "启动 {#AppName}"; Flags: nowait postinstall skipifsilent

[UninstallDelete]
; 日志与临时产物随卸载清掉；Config / Recipes / Templates 已在 [Dirs] 里标记保留，不动
Type: filesandordirs; Name: "{app}\Logs"
Type: files;          Name: "{app}\*.log"

[Code]
// ---------------------------------------------------------------------------
//  安装前检查 1：.NET Framework 4.8（Win10 1903+ 自带，Win7/8.1 需另装）
// ---------------------------------------------------------------------------
function IsDotNet48Installed(): Boolean;
var
  release: Cardinal;
begin
  Result := RegQueryDWordValue(HKLM,
    'SOFTWARE\Microsoft\NET Framework Setup\NDP\v4\Full', 'Release', release)
    and (release >= 528040);   // 528040 = .NET Framework 4.8
end;

// ---------------------------------------------------------------------------
//  安装前检查 2：目标目录里是否已有更高版本（防止误降级）
// ---------------------------------------------------------------------------
function InitializeSetup(): Boolean;
var
  existing: String;
begin
  Result := True;

  if not IsDotNet48Installed() then
  begin
    if MsgBox('未检测到 .NET Framework 4.8。' + #13#10 +
              'Windows 10 1903 及以上系统自带；Win7 / 8.1 请先安装后再继续。' + #13#10#13#10 +
              '仍要尝试安装吗？', mbConfirmation, MB_YESNO) = IDNO then
    begin
      Result := False;
      Exit;
    end;
  end;

  // 已有安装：提示将升级（同 AppId，配置与配方会保留）
  if RegQueryStringValue(HKLM,
       'SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\{8F3C2A74-6B1D-4E52-9C7A-2D5E1B0F9A31}_is1',
       'DisplayVersion', existing) then
  begin
    if MsgBox('检测到已安装版本 ' + existing + '。' + #13#10 +
              '将继续覆盖安装（Config / Recipes / Templates 会保留）。', mbInformation, MB_OKCANCEL) = IDCANCEL then
      Result := False;
  end;
end;
```

### 5.1 几个"会踩"的点

| 坑 | 现象 | 处理 |
|---|---|---|
| 数据目录被覆盖 | 升级后配方/配置丢失 | **不要把 `Config\Recipes\Templates` 加进 `[Files]`**；用 `[Dirs]` + `uninsneveruninstall` 只建目录 |
| `thirdparty` 层级被压平 | 启动报"找不到 opencv_world455.dll" | `[Files]` 必须带 `recursesubdirs createallsubdirs`，且 `DestDir` 保留 `thirdparty` |
| 程序正在运行 | 覆盖 exe 失败 / 提示"文件被占用" | `CloseApplications=yes`（Inno 6 会自动请求关闭并重试） |
| 装到 Program Files 后无法保存配置 | 参数改了重启就丢 / 报"拒绝访问" | 方案 A 装 `D:\`；或给 `[Dirs]` 加 `Permissions: users-modify`；彻底做法是方案 B |
| 卸载把现场配方删了 | 客户损失配方 | `[Dirs]` 的 `uninsneveruninstall`；`[UninstallDelete]` 只清 Logs |
| 版本号忘记改 | 安装包显示旧版本 | `#define AppVersion GetFileVersion(...)` 从 exe 读，不再手写 |

## 6. 出包、分发与升级

### 6.1 编译

```bat
:: GUI：打开 installer\setup.iss → Build → Compile
:: 命令行（推荐，可进脚本）：
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\setup.iss
```

产物：`installer\Output\VisionPlatform-1.0.11.0-setup.exe`

### 6.2 静默安装（批量装机 / 远程部署）

```bat
VisionPlatform-1.0.11.0-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART ^
    /DIR="D:\VisionPlatform" /LOG="%TEMP%\vp_install.log"
```

| 参数 | 作用 |
|---|---|
| `/VERYSILENT` | 完全无界面（连进度条都不显示） |
| `/SUPPRESSMSGBOXES` | 不弹任何确认框 |
| `/DIR="..."` | 指定安装目录（跳过目录页） |
| `/LOG="..."` | 写安装日志，现场排障必留 |
| `/NORESTART` | 即使需要也不重启 |

### 6.3 升级

- 直接**再跑一次新版安装包**即可：`AppId` 相同 → Inno 识别为升级 → 覆盖 `exe/DLL/thirdparty`，`Config/Recipes/Templates` 不受影响。
- 现场更省事的做法（不改安装器）：只替换 `exe + DLL + thirdparty\`，这也是 `DEPLOY.txt` 里写的升级口径。
- **降级**要显式允许：`/ALLOWDOWNGRADE=yes`（默认会被拒绝，防误操作）。

### 6.4 签名（可选，但有条件就该做）

未签名的安装包在客户机上常触发 SmartScreen"未知发布者"，杀软也可能拦。

```bat
:: 有代码签名证书（EV / OV）时：
signtool sign /fd sha256 /tr http://timestamp.digicert.com /td sha256 ^
    /f "codesign.pfx" /p "密码" installer\Output\VisionPlatform-1.0.11.0-setup.exe

:: 仅内网测试：自签名证书（客户机需导入证书，否则仍报警）
makecert -r -pe -n "CN=VisionPlatform Test" -ss My -len 2048 test.cer
```

## 7. 若将来要装进 Program Files（方案 B 的改动要点）

不改代码硬装 `C:\Program Files` 会遇到"配置存不下来"。正确做法是**数据根与程序根分离**：

1. `src\VisionPlatform\Core\AppPaths.cs` 增加"数据根"概念：
   - 程序目录只读 → 数据根 = `%ProgramData%\VisionPlatform`
   - 便携运行（目录可写）→ 数据根 = 程序目录（保持现状，兼容 U 盘/绿色版）
2. `Config`、`Recipes`、`Templates`、`Images`、`Logs`、`Calibrations`、`OCRModel` 全部挂在数据根下。
3. 首次启动做一次"老数据迁移"（把程序目录里的 `Config\appconfig.json` 等搬到数据根）——与 1.0.10.0 做的根目录→`Config\` 迁移是同一套路。
4. 安装脚本 `[Dirs]` 改为 `{commonappdata}\{#AppName}`，`DefaultDirName={autopf}\{#AppName}`。

工作量：约 1 天（含 Smoke 回归 + 现场升级演练）。**没有这个需求就先别做**。

## 8. 交付前的验收清单

在**一台干净机器**（最好是没装过开发环境的 Win10 x64）上依次确认：

- [ ] 安装包双击 → 中文向导 → 可改目录 → 装完能创建桌面快捷方式
- [ ] 启动无"缺少 xxx.dll"弹窗；`<安装目录>\Config\appconfig.json` 自动生成
- [ ] 相机管理能枚举到相机、能打开（USB / 模拟相机）
- [ ] 能导入工程包 / 新建配方，`Recipes\` 下有内容，重启后仍在
- [ ] 流程能跑通（模拟相机或本地图片），主界面出图 + OK/NG
- [ ] 通讯能连 Modbus（可用 `tools\comm\modbus_slave_sim.py` 起本机从站自证）
- [ ] 卸载：程序目录清空，**`Config / Recipes / Templates` 保留**
- [ ] 再装一次（同版本）→ 识别为修复/覆盖，数据仍在
- [ ] 装新版 → 版本号变化正确，数据仍在
- [ ] 静默安装 + `/LOG` 日志无 ERROR

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 安装时提示"需要 .NET Framework 4.8" | Win7 / 早期 Win10 | 先装 `.NET Framework 4.8`（离线包约 110 MB），或升级系统 |
| 装完启动报 `0xc000007b` | 32/64 位混用 | 本项目是 **x64**，确认安装包内 `thirdparty` 为 x64 版本（`publish.bat` 从 `bin\x64\Release` 取，天然正确） |
| 杀软报毒 / 被删 | 未签名 + 自解压行为 | 代码签名；或把安装目录加白名单；不要用 UPX 等压缩壳 |
| 双击无反应 | UAC 被策略禁止提权 | 改用方案 C（每用户安装，`PrivilegesRequired=lowest`） |
| 换机器后配方没了 | 配方在安装目录内 | 用「工程包导出」（`ProjectBundle`）迁移，或直接拷 `Recipes\` |
| 端口 9100 / 502 被占 | 同机其它程序占用 | 在通讯界面临时改端口；安装器与端口无关，不用动 |

## 10. 一页速查

```
准备：装 Inno Setup 6 → 仓库加 installer\{setup.iss, app.ico}

出包：version.bat 1.0.11.0
      build.bat Release
      publish.bat [--with-models]
      ISCC installer\setup.iss
      → installer\Output\VisionPlatform-1.0.11.0-setup.exe

装机：双击（向导）/ /VERYSILENT /DIR="D:\VisionPlatform" /LOG=...

升级：再跑新包（同 AppId，数据保留）；或只换 exe+DLL+thirdparty

卸载：程序清空，Config/Recipes/Templates 保留

签名：signtool sign /fd sha256 /tr <时间戳> /f cert.pfx 包.exe
```
