| 路径 | 说明 | 是否随升级保留 |

## 2. 三种校验模式（`Config\appconfig.json`）

```jsonc
{
  "System": {
    "LicenseMode": "Off",       // Off（默认）| Warn | Enforce
    "LicenseTrialDays": 0,      // 无证时的试用天数，0 = 不给试用
    "LicenseMinFingerprintMatch": 3   // 机器指纹匹配阈值（3/5 默认）
  }
}
```

| 模式 | 行为 | 用在哪 |
|---|---|---|
| `Off`（默认） | **完全不校验**，只写一条含机器码的启动日志 | 框架阶段 / 内部开发机 |
| `Warn` | 校验并记录结果，**不拦截**启动 | 试运行：先看日志里各机器是不是都 Valid |
| `Enforce` | 不可用即弹「软件授权」窗口；用户未导入有效证 → 退出 | 正式发版 |

> 缺字段 / 值写错一律按 `Off` 处理（`DataContractJsonSerializer` 缺 string 得到 `null`，
> 归一化后就是 `Off`）—— 手改坏配置不会让软件起不来。

## 3. 令牌格式（与签发工具的接口）

```
VLIC1.<base64url(payload JSON)>.<base64url(ECDSA P-256 签名 64 字节)>
```

payload 的 JSON 键名**必须与 `LicenseInfo` 的 `[DataMember(Name=…)]` 逐字一致**：

```jsonc
{
  "v": 1, "no": "VP-20261122-0001", "prod": "VisionPlatform",
  "edition": "Pro", "cust": "苏州XX自动化有限公司",
  "machine": "7K3M-9QZP-2XLV-8WDB",
  "fp": ["a1b2c3d4", "…5 项"],
  "issued": "2026-11-22T08:00:00Z",
  "expire": "2027-11-22T00:00:00Z",   // 空 = 永久
  "features": ["flow", "comm", "ocr", "3d"],
  "maxCameras": 4, "maxFlows": 8, "note": ""
}
```

校验顺序（**不可调换**）：拆三段 → 校验前缀 → **对 payload 原始字节验签** → 反序列化
→ 产品码 → 机器指纹 → 有效期（含回拨下限）。

## 4. 接入正式公钥（签发工具就绪后唯一要改的代码）

1. 打开 LicenseTool → 「密钥」页 → 复制 **公钥**（Base64 的 SubjectPublicKeyInfo，约 124 字符）。
2. 填进 `src\VisionPlatform\Core\Licensing\LicenseDefaults.cs` 的 `LicensePublicKeys.Keys`：

```csharp
private static readonly string[] Keys =
{
    "MFkwEwYHKoZIzj0CAQYIKoZIzj0DAQcDQgAE...",   // ← 粘这里
    // 轮换期可并存第二个公钥，老许可证继续有效
};
```

3. 重新 `build.bat Release`。此后：
   - `LicenseMode=Warn` 跑一轮，确认现场各机器日志里都是 `授权校验（Warn）：授权有效｜…`；
   - 再改 `Enforce` 正式发版。

> **公钥不是秘密**，可以随客户端发布；**私钥只在发证机**（DPAPI + 离线备份），
> 本仓库不含任何私钥代码路径。

## 5. 机器码

5 项指纹，各取 `SHA256(原始值)[0..3]` 的 8 位十六进制：

| # | 项 | 来源 | 换什么会变 |
|---|---|---|---|
| 1 | 主板 UUID | WMI `Win32_ComputerSystemProduct.UUID` | 换主板 |
| 2 | CPU ID | WMI `Win32_Processor.ProcessorId` | 换 CPU |
| 3 | 系统盘卷序列号 | `GetVolumeInformation`（程序所在盘） | 格式化 |
| 4 | MachineGuid | `HKLM\SOFTWARE\Microsoft\Cryptography` | 重装系统 |
| 5 | 物理网卡 MAC | `NetworkInterface`（排除虚拟/回环/隧道） | 换网卡 |

- 机器码（给人抄）= `Base32(SHA256(5 项拼接))` 前 16 字符，`XXXX-XXXX-XXXX-XXXX`
- 许可证里存 5 个短哈希，校验时按 **≥3/5 匹配** → 换网卡/换硬盘不锁死，整机更换必失败
- 某项采集不到 → 该短哈希为空串，**不参与比对**（界面会标"指纹降级"），不会因此拒绝出码

现场看机器码的三种方式：
1. 启动日志（`Logs\logs.db` 搜"机器码"，`Off` 模式也会记）
2. `VisionPlatform.exe --license` → 打开授权窗口，可一键复制
3. 强制校验失败时弹窗顶部

## 6. 状态语义（`LicenseStatus`）

| 状态 | 含义 | 是否可用 | 建议动作 |
|---|---|---|---|
| `Valid` | 授权有效 | ✅ | — |
| `Trial` | 试用期内（`LicenseTrialDays > 0`） | ✅ | 提醒导入正式证 |
| `Missing` | 没有 `license.lic` | ❌ | 导入许可证 |
| `Expired` | 已过期 | ❌ | 续签后换文件 |
| `NotYetValid` | 签发时间在未来（系统时间被调过） | ❌ | 校正系统时间 |
| `MachineMismatch` | 指纹不足阈值 | ❌ | 用本机机器码重新签发 |
| `SignatureInvalid` | 签名不符（文件被改 / 非本产品签发 / 公钥未内置） | ❌ | 重新导出 .lic |
| `ProductMismatch` | 拿到了别的产品许可证 | ❌ | 换正确的证 |
| `TokenVersionUnsupported` | `VLIC2` 等新格式 | ❌ | 升级客户端 |
| `Malformed` | 缺段 / Base64 坏 / JSON 残缺 | ❌ | 重新导出 .lic |
| `Error` | IO / 权限等环境问题 | ❌ | 查目录权限 |

时间回拨：`state.bin` 记录"最近一次成功校验时间"（HMAC 与机器绑定），
判定基准 `now = max(系统时间, 记录时间)` —— 把系统时间调回去不会让过期证复活；
删掉 `state.bin` 只影响回拨检测（视为首次运行），不影响授权有效性。

```text

④ 先在 Config 里设 LicenseMode=Warn 跑一周，确认日志无 MachineMismatch

⑥ 升级部署：只换 exe/DLL/thirdparty，保留 Config / Recipes / Templates / License
```
